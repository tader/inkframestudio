# Pixel Font Attribution

This project vendors bitmap source assets from [`teryror/pixel-fonts`](https://github.com/teryror/pixel-fonts) for:

- `PX Sans`
- `PX Mono Special`

Local source backups live under:

- `/Users/thomas/openepaperlink-codex/third_party/pixel-fonts/PX Sans`
- `/Users/thomas/openepaperlink-codex/third_party/pixel-fonts/PX Mono Special`

Generated runtime glyph data is produced by:

```bash
npm run import:pixel-fonts
```
